## LeetCode 212 - Word Search II

### Concepts:
- Trie (Prefix Tree)
- DFS Traversal
- Backtracking
- Prefix Pruning

### Key Learning:

Instead of searching every word separately, a Trie allows multiple words to share prefixes and helps eliminate unnecessary searches during DFS traversal.
